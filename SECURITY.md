# Security policy

## Reporting a vulnerability

Please do not publish exploitable details or sensitive proof-of-concept material in a public issue. Contact the repository owner privately through the contact method listed on the GitHub profile and include a concise description, affected version, impact and safe reproduction steps.

Do not include real client data, credentials, access tokens, private keys or unredacted assessment evidence.

## Scope

This policy covers vulnerabilities in the SCOPEZERO project itself. It does not authorize testing third-party systems. Obtain explicit permission before assessing any target.
