# SCOPEZERO Browser Capture


The SCOPEZERO Browser Capture extension connects a supported browser to the local SCOPEZERO assessment platform.

## Installation

1. Open `brave://extensions` or `chrome://extensions`.
2. Enable Developer mode.
3. Select Load unpacked.
4. Select the `browser-extension` directory.
5. Open the extension settings.
6. Configure the SCOPEZERO backend URL, active scan ID, authorized root domain and capture token.

## Security

- Use only with authorized assessment targets.
- Keep capture tokens private.
- Do not commit browser profiles, credentials or private certificates.
- Captured traffic may contain sensitive information.
- Remove the extension when it is no longer required.

## Development

The extension source is maintained in this directory. See the main SCOPEZERO documentation for backend configuration and setup.
