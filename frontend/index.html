HTTP Request Lab

Read-only GET/HEAD replay against already-discovered, in-scope public hosts. Redirects are not followed; response capture is capped. No state-changing methods.

Web vulnerability checks

Low-impact, reproducible GET-only checks for inert XSS marker reflection, SQL error disclosure, URL-parameter SSRF candidates and cookie/header hardening. No exploit payloads, internal-network requests or state-changing methods. IDOR/BOLA is investigated through the authorization matrix below.

Differential verification workbench

Repeatable GET-only comparisons: stable double baseline, inert XSS marker comparison, quote-only SQL error/difference check, and same-object response comparison across two authorized test identities. Auth headers are transient and are never persisted.

For IDOR, provide separate JSON headers for two accounts you are authorized to test. Example: {"Authorization":"Bearer TEST_TOKEN"}. Do not use production credentials.

Authenticated web testing sessions

Store reusable test identities with encrypted-at-rest headers. Verify identity reachability, rotate credentials manually, compare the same GET/HEAD resource across two identities, and link comparisons to an existing finding. Back up the local vault key alongside the database.

API authorization matrix

Record manual results using authorized test identities. SCOPEZERO does not infer access control from status codes alone.

NETWORK DISCOVERY

Nmap · Port & service discovery

TCP connect scan, top 100 ports, light service detection and bounded host timeout.

TEMPLATE-BASED CHECKS

Nuclei · Safe templates

Restricted to misconfiguration, exposure and TLS tags; excludes intrusive, fuzz and DoS tags. No matches means these selected templates returned no findings, not that the host is vulnerability-free.

WEB DISCOVERY

Katana · Endpoint crawling

Depth-2 crawl with same-host URL filtering. Discovered URLs are observations, not vulnerabilities.

PASSIVE RECONNAISSANCE

Subfinder · Subdomain discovery

Passive source-based enumeration only. Results are candidate hostnames; DNS resolution and ownership must be verified.

BOUNDED CONTENT DISCOVERY

Gobuster · Directory enumeration

Small built-in path list, six-host cap, five workers and request delay. Findings are HTTP response indicators, not proof of sensitive data exposure.

API ENDPOINT DISCOVERY

SCOPEZERO · API path probe

Checks a bounded list of common API, OpenAPI, Swagger and GraphQL paths using GET requests. No authentication bypass, fuzz payloads or state-changing methods.

PASSIVE DNS ENUMERATION

Amass · Passive intelligence

Passive-only Amass enumeration. No brute force, port scanning or active validation. Results are added as candidate hostnames.

DNS RECORD INTELLIGENCE

DNSx · Multi-record resolution

Resolves A, AAAA, CNAME, MX, NS and TXT records for discovered in-scope hostnames. No zone transfers or brute force.

CLOUD ASSET ENUMERATION

Cloud Enum · DNS indicators

Checks a small fixed set of common cloud-related hostnames and provider CNAMEs using DNS only. It does not access buckets, cloud accounts or objects.

CERTIFICATE TRANSPARENCY

CRT.sh · Certificate discovery

Searches public Certificate Transparency logs and adds matching in-scope hostnames to the asset inventory.

MANUAL SEARCH INTELLIGENCE

Google Dorking

Builds targeted Google search queries for indexed subdomains, public documents, login portals and API documentation. Searches open manually in Google.

REGISTRANT RELATIONSHIPS · API

Reverse WHOIS · Whoxy

Searches domains associated with an explicitly supplied company, owner name, email or domain-name keyword. Provider API may consume paid credits.

ROOT DOMAIN INTELLIGENCE · API

SecurityTrails

Uses the SecurityTrails API to discover historical/current subdomain intelligence. Requires SECURITYTRAILS_API_KEY.

PUBLIC REPOSITORY INTELLIGENCE · API

GitHub Recon Tools

Searches public GitHub code metadata for the root domain and returns repository/path references only. Requires GITHUB_TOKEN; no secrets or file contents are downloaded.

INTERNET EXPOSURE INTELLIGENCE · API
